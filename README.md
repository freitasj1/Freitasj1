# About Me

**Embedded Firmware Developer | Computer Engineering Student**

I am a Computer Engineering student at INATEL, with a technical background in Electronics and Telecommunications from ETE FMC.

My main focus is embedded firmware development, with hands-on experience in C/C++, FreeRTOS, ESP32, Nordic Semiconductor platforms, Bluetooth Low Energy, and LoRa-based systems. I am interested in low-level development, embedded communication, real-time systems, and the integration of hardware and software.

I am currently developing **MachineGuard**, an embedded predictive maintenance system for rotating machinery based on vibration analysis and edge processing.

---

## Featured Project

### MachineGuard

**Embedded predictive maintenance system for rotating machinery**

MachineGuard is a personal embedded systems project focused on monitoring and analyzing machine vibration directly at the edge.

The system uses an **ESP32-S3** to acquire vibration data, perform digital signal processing, extract relevant features, and identify abnormal operating conditions using a statistical baseline.

**Technologies**

`C` `ESP-IDF` `FreeRTOS` `ESP32-S3` `DSP` `FFT` `BLE` `MQTT` `GitHub Actions`

[View Repository](https://github.com/freitasj1/MachineGuard)
